# Reliability Criteria & Source Weighting

Sources are partitioned into 3 reliability tiers:

| Tier | Source Types | Weight | Verification Protocol |
| :--- | :--- | :---: | :--- |
| **Tier 1 (Authoritative)** | Official distributors (MOENCO), Government Ministries (MoTL, MoFED, ECC), OEM technical manuals. | **1.00** | Cross-referenced against published federal decrees and manufacturer specifications. |
| **Tier 2 (High Reliability)** | Certified independent EV workshops, licensed import houses (Sara, Zemen), commercial fleet work orders. | **0.85** | Physical verification of repair tickets and component stock. |
| **Tier 3 (Moderate Reliability)** | Online classifieds (Jiji, Mekina), Telegram groups, TikTok reviews, social forums. | **0.65** | Two-point cross-listing verification and phone verification. |
