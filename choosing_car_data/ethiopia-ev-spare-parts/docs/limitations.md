# Data Limitations

1. **Informal Gray Market Transactions**: A considerable volume of spare parts enters Ethiopia through passenger baggage or unmanifested regional channels, escaping official customs statistics.
2. **Odometer Telemetry Gaps**: Real-world component failure mileage is based on self-reported workshop intake logs rather than automated CAN-bus telemetry.
3. **Software Lock Constraints**: Certain modern components (e.g., Volkswagen MEB modules) require online manufacturer token authorization for component protection removal, distorting raw hardware availability metrics.
